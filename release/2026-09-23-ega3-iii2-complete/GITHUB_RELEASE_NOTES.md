# EGA III-2까지의 한국어 EGA 누적판

이 릴리스는 기존 한국어 EGA 누적 계보를 EGA III-1 완역에서 EGA III-2
완역까지 확장한다. 691쪽 독자판은 EGA 0_I, EGA I, EGA II, EGA III-1,
EGA III-2 전체를 포함하며, EGA III의 뒤 권과 후속 권은 이 버전의 범위가
아니다.

파일은 이용과 보존을 위해 누적 독자용 PDF, 완전 조립형 직접 LaTeX,
완전 모듈식 원본 트리, 범위가 제한된 증거·출처, SHA-256 목록 순으로
배치했다. 직접 LaTeX는 비공개 입력에 의존하는 얇은 주 파일이 아니라
누적 본문 전체이다.
