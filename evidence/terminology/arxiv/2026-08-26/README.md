# EGA Korean terminology source set — 2026-08-26

This directory retains three primary arXiv algebraic-geometry papers as English semantic and type controls for EGA II onward. They are not Korean lexical authorities. A bounded search found no qualifying Korean-language algebraic-geometry paper on arXiv; that is a scarcity finding, not proof of nonexistence.

Korean lexical choices must instead combine the exact French definition with current professional Korean usage. The standing witnesses are the KAIST Mathematical Sciences research-field page, two bilingual KAIST thesis records, and the Korean Mathematical Society terminology database. Current professional usage reinforces `스킴`, `층`, `사상`, `구조층`, `연접층`, `아핀다양체`, `폐포`, and `기약성분`; `도식` and `다발` remain recorded variants rather than automatic replacements.

For each nontrivial new term, the unit log must record all three layers: canonical French sense and formula type, an exact English arXiv semantic locus, and actually attested Korean professional usage. If Korean evidence is absent or conflicting, the term remains an explicit candidate in the external ledger; it is never silently canonized.

Exact URLs, authors, sizes, hashes, extracted-text contexts, Korean witness URLs, and this admission rule are recorded in `SOURCE_SET.json` and `AGKO-TERM-E159` in the standing `../2026-08-23/WORKFLOW_RECORD.jsonl`.
